# ملفات المحتوى (عدّلها بدون إعادة بناء التطبيق)
- config.json: روابط الـAPI، طرق حساب المواقيت، قواعد تصنيف الأذكار (exclude/daily)، إعدادات آية الساعة.
- cities.json: المناطق والمدن (الاسم، خط العرض، خط الطول). الصيغة: ["اسم المدينة", lat, lng] وللمدن خارج منطقة الزمن الافتراضية أضف رابعًا: "Africa/Cairo".
- muezzins.json: المؤذنون. file اسم الملف داخل base، أو رابط كامل يبدأ بـhttp.
- radios.json: إذاعات إضافية بصيغة [{"name":"...","url":"https://..."}].
- azkar.json (اختياري): إن وُجد يُستخدم بدل المصدر الخارجي. الصيغة في azkar.sample.json.
بعد التعديل ارفع الملف على GitHub، وتصل التعديلات للمستخدمين عند فتح التطبيق.
